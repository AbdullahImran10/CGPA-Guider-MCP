# PUCIT GPA/CGPA Agent

A conversational AI agent for calculating semester GPA and CGPA for PUCIT BS(CS) students.

### How to Run

1. Install dependencies: `pip install langchain langchain-groq python-dotenv streamlit`
2. Create a `.env` file and add your `GROQ_API_KEY`.
3. Start the application using: `streamlit run app.py`.
4. Open the Streamlit URL shown in the terminal and enter your GPA/CGPA questions.
